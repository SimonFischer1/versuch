# COLREG Navigator – Sound Signals Edition

Direkt für GitHub Pages / `navtool.de/colreg/`.

Dateien:
- `index.html`
- `styles.css`
- `app.js`

Erweiterungen:
- interaktive Schallsignale mit Play-Funktion und zeitlicher Visualisierung
- KVR 34, 35, 36 und 37
- umfangreiche SeeSchStrO-Signale inkl. NOK-/Schlepper-Signalen aus der Lernübersicht
- Navigationslichter / Kennungen
- IALA Kardinal- und Lateralsystem
- Praxisfälle und Knoten
- DE/EN
- Quellenlinks

Die Signaltöne werden mit WebAudio erzeugt; keine MP3/WAV-Dateien nötig.


## IALA / COLREG image sources

The buoy reference images use Wikimedia Commons / IALA diagrams as online fallbacks. Local files in `colreg/pic/` override them when uploaded. The referenced Wikimedia files are CC/GFDL licensed as indicated on their source pages. See the source links in `app.js` and the Wikimedia file pages before redistributing modified copies.

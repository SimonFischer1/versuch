SUPABASE EINRICHTEN (einmalig, ca. 10 Minuten)

1. Datenbank anlegen
   Supabase-Dashboard -> dein Projekt -> SQL Editor -> New query.
   Den kompletten Inhalt von supabase/schema.sql einfügen und auf Run klicken.
   Ergebnis "Success". Das legt Profile, Reisen, Mitglieder, Favoriten, Kalkulationen an und schaltet die Zugriffsregeln (RLS) ein.

2. Anmeldung einstellen
   Authentication -> Sign In / Providers -> Email: aktiv lassen, "Confirm email" AN lassen (wichtig, sonst kann sich jemand mit fremder E-Mail Einladungen holen). Minimale Passwortlänge 8.
   Authentication -> URL Configuration:
     Site URL: https://navtool.de
     Redirect URLs: https://navtool.de/** und https://www.navtool.de/**
   Authentication -> E-Mail-Vorlagen: Texte auf Deutsch anpassen (optional).
   Hinweis: Der eingebaute Mail-Versand von Supabase ist stark begrenzt (nur wenige Mails pro Stunde, gedacht zum Testen). Für echten Betrieb unter Authentication -> SMTP einen eigenen Mail-Dienst eintragen (z. B. Brevo oder Resend, beide mit kostenlosem Kontingent).

3. Schlüssel eintragen
   Project Settings -> API: "Project URL" (ist schon eingetragen) und den "anon"/"publishable" Key kopieren.
   In assets/supabase-config.js bei key: 'DEIN_ANON_KEY' einsetzen.
   NIEMALS den service_role / secret Key in die Website schreiben.

4. Hochladen
   Alle Dateien dieses Ordners in das GitHub-Repository legen (CNAME behalten). Danach unter https://navtool.de/konto/ registrieren und testen.

Kostenlose Version: Projekte ohne Aktivität werden nach etwa einer Woche pausiert. Im Dashboard mit einem Klick wieder starten, die Daten bleiben erhalten.

5. Admin-Bereich einrichten (navtool.de/admin/)
   a) Auf navtool.de/konto/ mit deinem normalen Konto (Simon-Luca Fischer) registrieren und die E-Mail bestätigen.
   b) Supabase -> SQL Editor -> New query: Inhalt von supabase/admin.sql einfügen.
   c) Ganz unten im Skript DEINE@EMAIL.DE durch die E-Mail dieses Kontos ersetzen, dann Run.
   d) Auf navtool.de/admin/ mit diesem Konto anmelden. Alle anderen Konten bekommen von der Datenbank keinen Zugriff.
   Dort siehst du: Anzahl Registrierte, Registrierung und letzte Anmeldung, Namen, E-Mail-Adressen. Du kannst Name und E-Mail ändern, ein neues Passwort setzen und Konten löschen.
   Passwörter selbst kann niemand anzeigen (Supabase speichert nur einen Hash). Das ist technisch so gewollt.

NAVTOOL / INFO

Bedienung

01 / Start & Ziel

Orte über die Suchfelder suchen oder direkt über „Start auf Karte“ bzw. „Ziel auf Karte“ setzen.

02 / Waypoints

„Waypoint hinzufügen“ aktivieren und auf die Karte klicken. Waypoints können anschließend verschoben oder gelöscht werden.

03 / Berechnung

Die Distanz wird aus allen Streckenabschnitten berechnet. Fahrzeit = Distanz / Geschwindigkeit.

04 / Sea Route

Für eine echte nautische Seeroute mit Fahrwassern, TSS und Landumfahrung wird ein SeaRoutes-Proxy benötigt. Die lokale Berechnung funktioniert unabhängig davon.

ROUTING-HINWEIS

Im Modus „SEA ROUTE“ wird die maritime Route über den konfigurierten SeaRoutes-Proxy berechnet. Im Direktmodus wird die Großkreisroute berechnet.

SYSTEM INFORMATION

Maritime Routing

Die SEA-ROUTE-Variante verwendet eine maritime Routing-Engine und kann Start, Ziel und mehrere Waypoints als gemeinsame Route verarbeiten.

Waypoints

Waypoints können direkt auf der Karte gesetzt, verschoben und gelöscht werden.

ETA

Die ETA wird anhand der Routendistanz, der eingegebenen Geschwindigkeit und der Abfahrtszeit berechnet.
